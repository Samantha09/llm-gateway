## API 文档

服务启动后可访问：

- Gateway Swagger UI: `http://localhost:8080/docs`
- Control Plane Swagger UI: `http://localhost:8081/docs`
- Gateway OpenAPI JSON: `http://localhost:8080/json`
- Control Plane OpenAPI JSON: `http://localhost:8081/json`
